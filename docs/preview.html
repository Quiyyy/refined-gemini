从当前后端开发实践来看，各核心网络层次的职责划分如下：

层次 解决的问题 开发中对应什么
IP 数据发往哪台机器 IP 地址、路由
TCP 提供可靠、有序的字节流 连接、重传、流量控制
TLS 加密传输、验证服务端身份 HTTPS 证书
Web 框架 将请求映射到业务处理逻辑 FastAPI 路由、参数校验、依赖注入

通常 HTTP/1.1、HTTP/2 使用 TCP；HTTP/3 使用基于 UDP 的 QUIC。例如：

</> HTTP 复制 
POST /runs HTTP/1.1
Content-Type: application/json
Idempotency-Key: request-123

{"message": "查询附近的营养门诊"}

HTTP 是无状态协议，意思是协议本身不要求服务端记住前一次请求的业务上下文。应用仍然可以通过 Cookie、Token 或数据库中的 session_id 实现登录与会话状态。
